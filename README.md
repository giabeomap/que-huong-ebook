# Quê Hương – Những Vùng Trời Của Tổ Quốc (Sách Điện Tử)

Trang web đọc sách điện tử tương tác với hiệu ứng lật sách 3D chân thực, nền gradient đổi màu và chuyển động theo nhịp điệu âm thanh, nhạc nền xuyên suốt, chế độ tự động nghe & tự động lật trang.

## Xem trực tuyến (GitHub Pages)
- https://giabeomap.github.io/que-huong-ebook/

## Chạy cục bộ
```bash
node server.js
```
Mở trình duyệt tại `http://localhost:8123/`.

## File nguồn
Toàn bộ thư mục nguồn gốc (`file nguồn.zip`, ~555 MB) được đính kèm trong mục **Releases (`v1.0.0`)** do vượt quá giới hạn kích thước 100 MB mỗi tệp của Git thông thường.
